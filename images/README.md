## Swapping in your own photos

Real photos of Arasta beat stock every time. To replace one, export it as WebP
(Squoosh does this well), keep the same filename and roughly the same size, and
drop it in this folder:

- Gallery and experience photos: about 1000px on the long side, any ratio
- Visit photo (`storefront.jpg`): about 960×1280, portrait
